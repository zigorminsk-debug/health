## Возможности

- 🩸 **Общий анализ крови** (гемоглобин, эритроциты, лейкоциты, тромбоциты, лейкоцитарная формула, СОЭ).
- 🧪 **Биохимия крови** (глюкоза, холестерин, ЛПНП/ЛПВП, триглицериды, печеночные и почечные пробы, калий, натрий, железо, ТТГ).
- 🚰 **Общий анализ мочи** (цвет, плотность, рН, белок, глюкоза, кетоновые тела, эритроциты, лейкоциты, нитриты, билирубин).
- 🩸 **Коагулограмма** (МНО, АЧТВ, фибриноген).
- 💓 **ЭКГ** — загрузка фото/сканов кардиограммы, комментарии и подсказки по ключевым словам (ознакомительно).
- 📋 Для **каждого** показателя указаны **референсные границы** (нормы) с учётом пола там, где это важно.
- ✏️ **Поле ввода результата** напротив каждого показателя; автоматическая подсветка отклонений (↓/↑).
- 🔍 По кнопке «Анализировать» — **персональные рекомендации**:
  - на что обратить внимание;
  - какие состояния/заболевания могут сопровождаться отклонениями;
  - типичная симптоматика;
  - к какому врачу обратиться.
- 💾 Сохранение истории анализов в памяти устройства, экспорт/импорт JSON.
- 📱 Устанавливается на телефон как **PWA** (с иконкой на рабочем столе, работает офлайн).
- 📦 Сборка в **APK** через Android WebView обёртку (см. ниже).

> ⚠ **Важно.** Информация в приложении носит **ознакомительный** характер и не заменяет очную консультацию врача. Не занимайтесь самолечением! При острых состояниях звоните 103.

## Группы анализов

Показатели сгруппированы по разделам:
1. Общий анализ крови (ОАК)
2. Биохимия крови
3. Общий анализ мочи (ОАМ)
4. Свёртывающая система (коагулограмма)

Для каждого показателя вы видите: название, **референсные значения (норму)**, поле для ввода результата и индикатор статуса.

## Как собрать APK (варианты)

### Вариант 1 — простой: PWA → APK через PWABuilder (онлайн)
1. Опубликуйте содержимое папки `bud-zdorov/` на любом хостинге (например GitHub Pages, Netlify, ваш csl.by).
2. Откройте [pwabuilder.com](https://www.pwabuilder.com/), вставьте URL сайта и нажмите **Package for Android** — скачается готовый `.apk`.

### Вариант 2 — через Bubblewrap (TWA) локально
```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest=https://ваш-сайт/manifest.webmanifest
bubblewrap build
```
На выходе получите `app-release-signed.apk`.

### Вариант 3 — кастомная WebView-обёртка (исходники уже подготовлены)
Исходники Android-проекта лежат в папке `../pkg/`. Для сборки нужен:
- JDK 17,
- Android SDK с platform-34 и build-tools 34.x,
- `aapt`, `d8`, `zipalign`, `apksigner`.

Команда сборки:
```bash
bash ../pkg/build-apk.sh
```

## Как запустить как PWA (без APK)
```bash
cd bud-zdorov
python3 -m http.server 8080
```
Откройте в Chrome на Android `http://<ваш-ip>:8080`, затем в меню браузера выберите **«Добавить на главный экран»** — приложение установится как нативное и будет работать офлайн.
