## Возможности

- 🩸 **25 групп показателей (254 теста):** ОАК, биохимия, липидный профиль, ОАМ,
  коагулограмма, гормоны (щитовидная железа, надпочечники, половые), витамины и
  микроэлементы (базовая и расширенная панели), маркёры воспаления, инфекции,
  гепатиты, витамины, коагулограмма расширенная и др.
- 📸 **OCR-распознавание** бумажного бланка анализов с фото (Tesseract.js).
- 💓 **ЭКГ:** загрузка фото/сканов, калибровка, измерение ЧСС и интервалов,
  автоанализ сегмента ST, расшифровка.
- 🤒 **Жалобы:** интеллектуальный симптомчекер (взвешенные триггеры, красные флаги,
  дифференциальные опросники) — навигация к врачу, НЕ диагноз.
- 📚 **Справочник** доказательной медицины (PubMed, Cochrane, ВОЗ, ГЭОТАР, КР Минздрава РФ…).
- 🔍 По кнопке «Анализировать» — персональные рекомендации: на что обратить внимание,
  возможные причины отклонений, типичная симптоматика и к какому врачу обратиться.
- 💾 История записей, анализ динамики по множественным записям, экспорт/импорт JSON.
- 🔑 PIN-защита доступа (хранится как солёный SHA-256).
- 📱 Работает как PWA в браузере (офлайн через Service Worker на http/https)
  и как APK-обёртка Android WebView.

> ⚠ **Важно.** Информация носит **ознакомительный** характер и не заменяет очную
> консультацию врача. Не занимайтесь самолечением! При острых состояниях звоните 103.

## Где хранятся данные

- В APK: важные ключи журнала — в приватных `SharedPreferences` приложения
  (переживают любые обновления поверх, но удаляются вместе с приложением).
- В браузере: `localStorage`.
- Для переноса между устройствами и резервных копий используйте
  «📤 Экспорт (JSON)» / «📥 Импорт» на вкладке «📋 История».

## Сборка APK

### Автоматически (GitHub Actions)
При каждом push в `main`/`arena/**` workflow **`.github/workflows/build-apk.yml`**
сам собирает и подписывает APK: готовый файл лежит в артефактах run
(`BudZdorov-apk`). Ручной запуск `workflow_dispatch` с галкой
`publish_release` additionally создаёт GitHub Release с APK.

### Локально
```bash
bash build-apk.sh
```
Скрипт сам находит JDK (`JAVA_HOME`/`javac` в PATH) и Android SDK
(`ANDROID_HOME`, иначе `./android-sdk`; необходимы `build-tools;30.0.3` и
`platforms;android-30`), генерирует манифест, ресурсы, dex, подписывает
постоянным ключом `budzdorov.jks` и кладёт результат в `BudZdorov.apk`.
Переменные окружения: `VERSION_CODE`, `VERSION_NAME`, `OUT_APK`,
`BUDZDOROV_KEYSTORE` / `BUDZDOROV_KEYSTORE_B64` / `BUDZDOROV_KS_PASS`.

Каталог `apk-build/` — чисто служебельный (пересоздаётся при сборке), из git исключён.

## Как запустить как PWA (без APK)
```bash
cd bud-zdorov
python3 -m http.server 8080
```
Откройте в Chrome на Android `http://<ваш-ip>:8080`, затем в меню браузера
**«Добавить на главный экран»** — приложение установится и будет работать офлайн
(Service Worker регистрируется только для http/https; в APK он не нужен).

## Структура проекта
```
bud-zdorov/            — веб-приложение (index.html, js/app.js, js/data.js, css, sw.js)
apk-build-tmp/         — исходники Java-обёртки (MainActivity, SimpleFileProvider)
NativeStorage.java     — мост хранения WebView (SharedPreferences)
build-apk.sh           — локальная сборка APK (тот же пайплайн, что в CI)
.github/workflows/     — автосборка APK в GitHub Actions
apk-build/             — служебный каталог сборки (в git не хранится)
```
